# Security Policy

If you have found a security vulnerability with nbsp.party, please send an email to security@nbsp.party with instructions to reproduce the issue.

If you have found a security vulnerability with nbsp in general, and not just nbsp.party, please see [nbsp's security policy](https://github.com/bearbearean/nbsp/blob/main/SECURITY.md) instead.

**Please do not report security vulnerabilities through public channels such as GitHub issues.**
